# HR-Analytics-Dashboard
Un tableau de bord Power BI interactif analysant l'attrition des employés, la démographie et les tendances RH par département, poste et tranche de salaire.

<img width="1903" height="1111" alt="Capture d&#39;écran 2026-09-18 110206" src="https://github.com/user-attachments/assets/adff9159-52df-4cf8-80dc-1406bc6fed91" />

> 🎉 Mon tout premier dashboard — projet réalisé pour apprendre Power BI de bout en bout : modélisation des données, mesures, visuels, et thème personnalisé.

## Indicateurs clés

- **Total Employees** — effectif total
- **Active Employees** — employés actifs
- **Attrition Counts / Rate %** — nombre et taux d'employés partis
- **Average Age** — âge moyen
- **Average Experience** — ancienneté moyenne

## Visuels

- Attrition par département, poste et tranche de salaire
- Attrition par genre et satisfaction au travail
- Répartition par tranche d'âge
- Tendance de l'attrition selon l'ancienneté
- Filtres interactifs : département et tranche d'âge

## Données

Fichier source : `HR_Analytics.csv` — contient EmpID, Department, JobRole, Age, YearsAtCompany, SalarySlab, Gender, JobSatisfaction, et le statut d'attrition.

> Jeu de données de démonstration à but pédagogique.

## Thème

Palette personnalisée **Executive Navy** :

| Couleur | Hex | Usage |
|---|---|---|
| Navy | `#1B2A4A` | Titres, en-têtes |
| Amber | `#E8A33D` | Attrition / accents |
| Gris | `#8C9BAB` | Données neutres |

Le thème est fourni dans `HR_Dashboard_Theme.json` (**Affichage → Thèmes → Parcourir les thèmes** dans Power BI Desktop).

## Utilisation

1. Clone ce repo.
2. Ouvre `HR_Analytics_Dashboard.pbix` dans Power BI Desktop.
3. Mets à jour le chemin vers `HR_Analytics.csv` si nécessaire.
