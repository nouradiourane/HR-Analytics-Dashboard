# HR-Analytics-Dashboard
Ce dashboard donne aux équipes RH une vue d'ensemble sur la composition de l'effectif et les facteurs d'attrition — qui part, de quel département, à quel niveau d'expérience, et comment cela se corrèle avec le salaire et la satisfaction au travail. Construit dans Power BI Desktop à partir d'un jeu de données brut (HR_Analytics.csv).
